# Project continuity

Before making changes, read these files in order:

1. `docs/PROJECT_CONTEXT.md` — purpose, scope, and architectural principles.
2. `docs/CURRENT_STATE.md` — what exists now and the active task.
3. `docs/ROADMAP.md` — phased implementation plan.
4. `docs/DECISIONS.md` — confirmed choices and open decisions.
5. `docs/HANDOFF.md` — concise notes for starting a fresh chat.

After any meaningful implementation or planning change, update the relevant
document(s). Keep `CURRENT_STATE.md` and `HANDOFF.md` accurate enough that a
new chat can continue without reconstructing context from conversation history.
