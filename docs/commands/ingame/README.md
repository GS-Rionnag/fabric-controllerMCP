# In-game

This branch becomes active when `mcp state` reports `ingame`.

## Available now

- [Settings](../settings/README.md) — direct client preferences and controls.
- [UI](../ui/README.md) — current-screen inspection and interaction.
- [Raw input](../input/README.md) — keyboard and mouse events.

## Planned branches

The following are reserved so the command tree remains stable as the project
grows:

- `ingame.player` — position, health, effects, inventory, and equipment.
- `ingame.world` — blocks, entities, chunks, dimensions, and screenshots.
- `ingame.interaction` — mine, place, attack, and use.
- `ingame.navigation` — travel, follow, avoidance, jobs, and cancellation.

These branches are not callable yet. Their pages and commands will be added
when the corresponding implementation phase is complete.

Return to the [command tree](../README.md).
