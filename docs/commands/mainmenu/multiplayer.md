# Main menu / Multiplayer

| Command | Required arguments | Purpose |
| --- | --- | --- |
| `mainmenu.multiplayer.list_saved` | none | Lists saved multiplayer servers. |
| `mainmenu.multiplayer.save` | `name`, `address` | Adds a server, or replaces it when `serverId` is supplied. |
| `mainmenu.multiplayer.remove_saved` | `serverId` | Removes one saved server. |
| `mainmenu.multiplayer.join` | `serverId` or `address` | Starts vanilla's normal connection flow. `name` is optional for an address. |
