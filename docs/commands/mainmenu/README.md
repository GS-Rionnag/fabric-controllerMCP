# Main menu

This branch is active when `mcp state` reports `mainmenu`. Settings and UI
remain available here through their shared branches.

- [Single-player](singleplayer.md) — list, create, and load local worlds.
- [Multiplayer](multiplayer.md) — manage saved servers and connect.

Runtime discovery:

```json
{ "command": "help", "arguments": { "path": "mainmenu" } }
```

Return to the [command tree](../README.md).
